# M2-T2 Log: Limitless TCG Scraping Pipeline

**Date:** 2026-05-13
**Status:** ✅ Complete

## Summary

Built Limitless TCG (One Piece TCG) scraper using Playwright instead of Steel browser sessions. Steel browser sessions are fundamentally broken in this environment (Chrome fingerprint generation fails in Podman container). Playwright works reliably.

## Key Design Decisions

- **URL:** `https://onepiece.limitlesstcg.com/cards/` (separate from main Pokémon site)
- **Playwright over Steel:** Steel browser sessions broken (fingerprint error in Podman). Playwright provides reliable JS rendering.
- **Two-tier approach:**
  1. `scrape_limitless_op()` — orchestrates full scrape of all sets/cards
  2. `_parse_card_page()` — parses individual card page HTML, extracts card metadata + prices
  3. `_get_all_sets()` — extracts set list from main cards page
- **Scrapes:** Card metadata (name, type, color, power, cost) + USD/EUR prices
- **card_version:** Set to `None` — alt art/versioning not yet extracted

## API Discovery

- Main cards page: `https://onepiece.limitlesstcg.com/cards/` — shows all sets with metadata
- Set pages: `https://onepiece.limitlesstcg.com/cards/{set-slug}/` — lists all cards in set
- Card pages: `https://onepiece.limitlesstcg.com/cards/{card-id}/` — individual card with prices
- No direct API found — all data rendered via JS after page load
