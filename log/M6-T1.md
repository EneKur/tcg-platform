# M6-T1 Log: ZyteSessionResource — Retry + Connection Management

**Date:** 2026-05-25
**Status:** ✅ Complete

## Summary

Created `ZyteSessionResource` — a Dagster resource wrapper around `ZyteAPI` that adds retry logic for transient failures, configurable connection pooling, and retry statistics tracking.

## What Was Built

### `src/tcg_platform/defs/zyte_resources.py`

- `ZyteSessionResource` class — thin wrapper around `ZyteAPI`
- `get()` method — wraps `ZyteAPI.get()` with retry logic for transient errors (ConnectionError, TimeoutError, 5xx, 429)
- Exponential backoff: 0.5s × (attempt + 1)
- `get_retry_stats()` — returns dict with `retries_attempted` count
- `zyte_session_resource` — Dagster `@resource` decorator
- Configurable via env vars:
  - `ZYTE_API_KEY` — required
  - `ZYTE_N_CONN` — connection pool size (default 2)

### Retry Behavior

| Error Type | Retry? | Max Retries |
|------------|--------|-------------|
| `ConnectionError` | ✅ | 3 (configurable) |
| `TimeoutError` | ✅ | 3 |
| HTTP 429 | ✅ | 3 |
| HTTP 5xx | ✅ | 3 |
| HTTP 4xx | ❌ | — |
