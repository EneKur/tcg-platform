## Summary

Integrated MinIO as the S3-compatible object store for the bronze layer. Created a `MinioClientResource` Dagster resource that handles connection, bucket creation, and basic CRUD operations.

## What Was Created

- `src/tcg_platform/resources/minio_client.py` — `MinioClientResource` class

- Updated `.env` with MinIO config

## Design Decisions

- **No bucket-name config on resource config** — bucket name comes from env var `MINIO_BUCKET` (default: `tcg-bronze`), not per-site config. All scraping outputs go to the same bucket with different prefixes.
- **`_ensure_bucket_exists` in `setup_for_execution`** — bucket is auto-created on first Dagster run if it doesn't exist.
- **MinIO runs locally in Podman** — `localhost:9000`, credentials `minioadmin/minioadmin`.

## MinIO Configuration

```bash
# Podman command to start MinIO
podman run -d \
  --name minio \
  -p 9000:9000 \
  -p 9001:9001 \
  -e "MINIO_ROOT_USER=minioadmin" \
  -e "MINIO_ROOT_PASSWORD=minioadmin" \
  docker.io/minio/minio server /data --console-address ":9001"

# Console: http://localhost:9001 (minioadmin/minioadmin)
```

## Resource API

```python
class MinioClientResource:
    endpoint: str              # from MINIO_ENDPOINT env
    access_key: str            # from MINIO_ACCESS_KEY env
    secret_key: str           # from MINIO_SECRET_KEY env
    bucket_name: str           # from MINIO_BUCKET env (default: tcg-bronze)
    secure: bool = False       # HTTP (not HTTPS) for local dev

    # Methods
    put_object(bucket, object_name, data: bytes, length, content_type)
    get_object(bucket, object_name) -> bytes
    list_objects(bucket, prefix) -> list[str]
```
