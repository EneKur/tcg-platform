### Key Methods

- `execute(query, params, fetch)` — single query with fetch modes
- `execute_many(query, params_list)` — batch insert
- `get_seen_ebay_item_ids()` — extracts item IDs from existing fact_events for idempotency
- `get_unparqueted_fact_events(source_region)` — backfill query for records missing parquet
- `mark_fact_events_parqueted(source_region)` — marks records as parqueted after backfill

### Backfill Tracking

`parqueted` column (default 0) tracks which records have been written to MinIO as parquet.
- 0 = not yet parqueted (backfill asset will pick these up)
- 1 = parqueted
