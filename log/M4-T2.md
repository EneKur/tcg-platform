## Summary

Created `MinioClientResource` — a Dagster `ConfigurableResource` wrapping the MinIO Python client with bucket auto-creation, object CRUD, and idempotency checks.

## What Was Built

### `src/tcg_platform/resources/minio_client.py`

- `MinioClientResource` class — extends `ConfigurableResource`
- `setup_for_execution` — connects to MinIO, auto-creates bucket if missing
- Configurable via env vars: `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET`

### Resource API

```python
minio_client.put_object(bucket, object_name, data: bytes, length, content_type)
minio_client.get_object(bucket, object_name) -> bytes
minio_client.list_objects(bucket, prefix) -> list[str]
minio_client.client  # raw Minio client (property)
```

### Storage Paths

| Path | Content |
|------|---------|
| `sold_images/{region}/{item_id}.jpg` | eBay card images |
| `sold_data/{region}/{item_id}.parquet` | Per-item sales records |
| `bronze/cardlist/partition_date={date}/cards.parquet` | Card catalog parquet |
| `bronze/fact_events/partition_date={date}/prices.parquet` | Price events parquet |

### Bucket Auto-Creation

`_ensure_bucket_exists()` runs in `setup_for_execution`. Bucket is created on first Dagster run if it doesn't exist.
