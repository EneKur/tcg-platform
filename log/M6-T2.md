# M6-T2 Log: eBay DE + UK Scraping Pipeline via Zyte API

**Date:** 2026-05-27
**Status:** ✅ Complete

## Summary

Built complete eBay DE and UK sold listing scraping pipelines using `ZyteSessionResource`. Each pipeline: (1) paginates search results via Zyte, (2) scrapes individual item pages, (3) writes inline per-item parquet to MinIO, (4) batch-inserts to SQLite. Proxies and fake cards are filtered out.

## Architecture

```
ebay_de_pipeline / ebay_uk_pipeline:
  ebay_de_sold_listings (asset)
      ├── scrape_ebay_listings() → item URLs via Zyte
      ├── for each URL:
      │     ├── zyte.get({browserHtml: True}) → item page HTML
      │     ├── parse_ebay_item_page() → PriceRecord[]
      │     ├── extract_item_image_url() → image URL
      │     ├── download_and_save_image() → MinIO
      │     ├── price_records_to_parquet() → MinIO sold_data/{region}/{item_id}.parquet
      │     └── records.append()
      └── return records

  bronze_ebay_de_sqlite_writer (asset)
      └── execute_many INSERT OR IGNORE → SQLite fact_events
```

## Regions & Configuration

| Region | URL | Currency | Date Format | Locale |
|--------|-----|----------|-------------|--------|
| DE | `ebay.de/sch...?PSA+One+Piece+TCG&LH_Sold=1` | EUR | German (`verkauft am`) | `de` |
| UK | `ebay.co.uk/sch...?PSA+One+Piece+TCG&LH_Sold=1` | GBP | English (`Sold ...`) | `en` |

## Key Parsing

- **Card ID:** Extracted from title, normalized (spaces→underscores), split base/version via `OP\d+` regex
- **Sold date:** German: `verkauft am D. Monat YYYY`; English: `Sold ... Mon D, YYYY`
- **Price:** Parsed from `data-testid="x-price-primary"` span, handles `,` decimal separator for DE
- **Language:** Detected via `"japan"`, `"japanese"` in title → `JP`, else `EN`
- **Proxy filter:** Titles containing `proxy`, `dummy`, `fake card`, `replica` are skipped

## Idempotency

- `sqlite_client.get_seen_ebay_item_ids()` — extracts item IDs from existing SQLite rows
- `scrape_ebay_listings()` skips any item_id already in the seen set
- SQLite uses `PRIMARY KEY (card_id, source_url)` — duplicate inserts are ignored
