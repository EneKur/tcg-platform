# M5-T1 Log: PriceCharting Scraping Pipeline

**Date:** 2026-05-13
**Status:** ✅ Complete (superseded by M6-T2 eBay pipeline)

## Summary

Built PriceCharting scraper using Playwright + BeautifulSoup. Uses `search-products?q=one+piece+tcg&type=prices` endpoint which returns full HTML table of card names, sets, and prices.

## What Was Built

### `src/tcg_platform/scraping/pricecharting.py`

- `scrape_pricecharting()` — main entry point
- `parse_pricecharting_html()` — pure parse function (unit-testable)
- Returns `list[PriceRecord]` with `event_type="price_update"`, `sold_date=None`

### Endpoint

```
https://www.pricecharting.com/search-products?q=one+piece+tcg&type=prices&ignore-preferences=true
```
No JS rendering needed — endpoint returns static HTML table.

### Parsed Fields

- `card_id` — normalized title
- `price` — low price (or high if low unavailable)
- `currency` — USD
- `set` — extracted from second column
- `scraped_from` — `pricecharting`

### HTML Structure Verified

```html
<tr>
  <td></td>
  <td>DON!! Card [One Piece Day '25]</td>  <!-- title -->
  <td>One Piece Japanese Promo</td>         <!-- set -->
  <td>$13.40</td>                            <!-- low price -->
</tr>
```
