## Summary

Research alternative services to Steel.dev for anti-ban browser sessions. Steel.dev has issues in this environment (Podman + macOS entropy issue causing Chrome fingerprint generation to fail).

## Problem Statement

Steel browser sessions are broken in this environment:
- Chrome fingerprint generation fails (Podman on macOS — entropy source issue)
- WebSocket connectivity (`wss://connect.steel.dev`) returns 502 Bad Gateway
- `--privileged` flag on container did not fix it

This blocks eBay scraping (M6) which requires browser session with cookies/auth.

## Research Goals

Find services that provide:
1. Anti-ban / fingerprint management
2. Browser session persistence (cookies, localStorage)
3. Free tier or low cost
4. Python SDK or REST API
5. Works reliably in containerized environments

## Findings

### Zyte API — ✅ WORKS for eBay DE

**Verified working** with real API key:
- Endpoint: `POST https://api.zyte.com/v1/extract`
- Auth: `auth=(api_key, "")` with Basic auth
- Key request params:
  - `url`: target URL
  - `browserHtml: true`: returns JS-rendered HTML
  - `actions: [{"action": "scrollBottom"}]`: scrolls to load all items
- Returns 1.4-2.4MB of HTML with all sold listings

**Parsing approach:**
- Select listings: `li.s-card`
- Sold date: regex on text `r'Verkauft\s+(\d+\.\s+\w+\s+\d{4})'`
- Price: regex on text `r'(EUR\s+[\d\.,]+)'`

**Results from eBay DE test:**
- 62 total listings on page 1
- 54 sold One Piece TCG cards extracted
- Dates: 13–22 May 2026
- Prices: EUR 24–2,825

**Limitation:** No session persistence (cookies/auth) — eBay DE sold listings are public, so this doesn't matter.

### Cloud API Comparison
| Service | Works? | Session Persistence | Cost |

| Zyte API | ✅ | ❌ (not needed for public data) | ~$5/mo free tier |

### Decision
**Use Zyte API** as primary anti-ban/cloud browser service. It works reliably, has a free tier, and eBay sold listings are public (no session auth needed).
