# M2-T3 Log: Card Image Download Pipeline

**Date:** 2026-05-22
**Status:** ✅ Complete

## Summary

Built image download pipeline that fetches card images from Limitless TCG CDN and uploads them to MinIO as `.webp` files. Handles base cards + alternate art variants (e.g., `?v=1`, `?v=2`). Idempotent — skips cards already in MinIO.

## Architecture

```
Limitless TCG Website (Playwright, per-set pages)
  → Extract all card_ids including ?v=1, ?v=2 variants
  → For each card: check if in MinIO (idempotency)
  → CDN URL: https://limitlesstcg.nyc3.cdn.digitaloceanspaces.com/one-piece/{SET}/{CARD}_EN.webp
  → Variant CDN: https://limitlesstcg.nyc3.cdn.digitaloceanspaces.com/one-piece/{SET}/{CARD}_p{N}_EN.webp
  → MinIO: cards/{set_code}/{card_id}.webp or cards/{set_code}/{card_id}_v{N}.webp
```

## CDN URL Patterns

| Card Type | CDN Filename |
|-----------|--------------|
| Base | `{CARD}_EN.webp` |
| Variant `?v=1` | `{CARD}_p1_EN.webp` |
| Variant `?v=2` | `{CARD}_p2_EN.webp` |

**Example:** `https://limitlesstcg.nyc3.cdn.digitaloceanspaces.com/one-piece/OP01/OP01-001_p1_EN.webp`

## MinIO Object Names

| Card Type | Object Key |
|-----------|------------|
| Base | `cards/OP01/OP01-001.webp` |
| Variant `?v=1` | `cards/OP01/OP01-001_v1.webp` |
| Variant `?v=2` | `cards/OP01/OP01-001_v2.webp` |

## Idempotency

Before downloading, checks `minio.client.stat_object()` to see if object already exists. If present, skips download. This allows re-running without re-downloading everything.

## Scraping Strategy

1. Visit main `/cards/` page → get list of all 49 sets
2. For each set: visit set page (e.g., `/cards/OP01/`) → extract all card links including `?v=N` variants
3. Deduplicate by `(card_id, variant)`
4. Process each card with idempotency check

**Variant discovery:** Limitless TCG uses `?v=1`, `?v=2` query params on card URLs for alternate printings. These map to `_p1`, `_p2` suffixes in CDN URLs.
