### 2. eBay US Bronze Layer Architecture
Designed and built the Bronze layer for eBay US listings:
- **Philosophy**: Bronze = raw, flat, everything-as-is. No filtering/bucketing. Silver later validates/cleans.
- **Storage**: Per-item parquet in MinIO (`bronze/listings/us/{item_id}.parquet`) + image binary in MinIO (`bronze/images/{card_id}_{card_version}_{item_id}.{ext}`)
- **No Zyte**: Uses plain `requests` with 1 req/sec rate limit

### 6. Sold Date Bug Found
English `sold_date` regex was broken — only 3 UK / 0 US rows had dates. The pattern `"Sold Mon, Jan 1, 2024"` didn't match any of the 3 alternatives in the regex. New regex in `ebay_bronze.py` fixes this.

### 7. Card ID Parsing Issues Found
Only 1-9% of rows had proper OP/EB set codes. Most titles like "14x One Piece TCG OP15" become garbage `card_id` values. The new scraper skips entries with no valid card_id at Bronze level; Silver will do full cardlist validation.

### 8. AUD Issue on eBay.com Found
eBay.com pages can show AUD prices/currency — not just `ebay.com.au`. New scraper detects this via `AU$`/`A$`/`AUD` in price text and assigns `currency=AUD`.
