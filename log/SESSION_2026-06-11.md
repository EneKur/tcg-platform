# Session 2026-06-11

## Branch
`2026-06-11-m9-t1-tcg-raw-layer`

## Goal
Brainstormed, spec'd, planned, and implemented M9-T1: introduce a new `tcg-raw` MinIO bucket for persistent raw HTML/images, so a future parser change can replay the transformer without re-paying Zyte API costs. The old single-stage scraper was split into:
- **Scraper** (network-only): writes raw bytes to tcg-raw.
- **Transformer** (offline): reads tcg-raw, writes structured bronze (parquet + SQLite).
- **Backfill** (one-time): fetches raw HTML for the 64+342 rows scraped before tcg-raw existed.
