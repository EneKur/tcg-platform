# M2-T1 Log: PriceCharting Scraping Pipeline

**Date:** 2025-05-13
**Status:** ✅ Complete

## Summary

Built PriceCharting scraper using Steel `scrape()` + BeautifulSoup. Uses `search-products?q=one+piece+tcg&type=prices` endpoint which returns full table HTML with card names, sets, and prices — no JS rendering needed.

## Key Design Decisions

- **Endpoint discovered via site inspection:** `https://www.pricecharting.com/search-products?q=one+piece+tcg&type=prices&ignore-preferences=true`
- **Pure parse function:** `parse_pricecharting_html()` takes HTML string, returns `list[PriceRecord]`
- **Separation of concerns:** parse vs scrape — parser is unit-testable without network
- **Single timestamp:** `scraped_at = datetime.utcnow()` captured once per scrape call
- **`sold_date=None`:** PriceCharting is price updates, not sales — sold_date is always NULL

## Verified HTML Structure

```html
<tr>
  <td></td>
  <td>DON!! Card [One Piece Day '25]</td>  <!-- title -->
  <td>One Piece Japanese Promo</td>         <!-- set -->
  <td>$13.40</td>                            <!-- low price -->
  <td></td>                                  <!-- mid price -->
  <td></td>                                  <!-- high price -->
</tr>
```
